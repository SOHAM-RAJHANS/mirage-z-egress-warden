# Reference material

This directory holds non-code reference material used while designing and validating
MIRAGE-Z. It is intentionally kept out of the build and test paths.

| Path | Contents |
| :--- | :--- |
| `linuxone_proof/` | LinuxONE verification proof notes for the camera-ready demo. |

Vendored clones of third-party IBM technical-resource repositories and third-party PDF
handbooks were removed before publication to keep this repository free of nested Git
repositories, large binaries and third-party copyright material. The authoritative,
read-only product specifications live in [`../documentation/`](../documentation/).

Consult the official IBM Z / LinuxONE documentation and the IBM Z Datathon participant
portal for the current platform guidance.
